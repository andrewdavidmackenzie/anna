Structs§

ClusterMembership
A message to track which physical servers are a part of which Anna membership (memory, disk) tier.
ClusterTopology
Cluster topology information published as ANNA_METADATA|cluster_topology so clients can discover thread counts at runtime.
KeyAccessData
A message to capture the access frequencies of individual keys for a particular server thread.
KeySizeData
A message to track metadata about how large each key in the system is.
ReplicationFactor
A message that captures the replication factor for an individual key.
ReplicationFactorUpdate
A message to propagate changes to a set of keys’ replication factors.
ScalingAlert
A scaling recommendation emitted by the monitor’s policy engine. An external system (operator tooling, orchestrator, etc.) consumes these alerts and provisions or decommissions infrastructure.
ServerThreadStatistics
A message to capture the periodic reporting of each server thread’s local statistics; these are aggregated by the monitoring system.
UserFeedback
Client-generated feedback used for system monitoring and planning.

Tier
