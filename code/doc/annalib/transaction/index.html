Client-side transactions for Read Committed and Item Cut Isolation. Client-side transactions providing Read Committed and Item Cut Isolation.

A [Transaction] buffers writes locally and caches reads for repeatable reads within the transaction. On commit(), all buffered writes are flushed to the server with a single dominating timestamp, making them atomically visible.

§Read Committed

Within a transaction, reads see only committed data from other clients. The client’s own uncommitted writes are visible via the local write buffer (read-your-writes within the transaction).

§Item Cut Isolation

Reading the same key twice within a transaction returns the same value (repeatable read). The first read is cached; subsequent reads return the cached value.

§Example

let mut txn = annalib::transaction::Transaction::begin(&mut client);

txn.put("key1", "value1");
let v = txn.get("key2").await?;   // reads from server, cached
let v2 = txn.get("key2").await?;  // returns cached value (repeatable)
assert_eq!(v, v2);

txn.commit().await?;              // flushes "key1" to server
